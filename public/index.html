Project Experience

Splunk to Elastic Migration Project

Westpac Banking Group | [Dates] | Engineer

Splunk Elastic Observability dashboard screenshot

Overview

Working as part of a team of 15 engineers on an ongoing migration from Splunk to Elastic, including thousands of existing dashboards and alerts. The project has been underway for four months, with migration and delivery work continuing.

Responsibilities

Supported the migration of dashboards and alerts across two different schemas and database structures. Created a field-mapping register as a single source of truth for field availability, compliance requirements, dashboard functionality, and alert behaviour. Also created de novo dashboards to support end-to-end observability.

Technology

Applied Elastic ESQL and translated Splunk queries into Elastic-compatible searches. Used multi-agent systems and automation platforms to support high-throughput dashboard creation.

Outcome

Continuing to deliver dashboards and alerts while building a repeatable migration workflow. The project aims to automate the migration of thousands of dashboards with high accuracy by using the field register as the source of truth. It is expected to save the organisation approximately $10 million per year, facilitate CI/CD development, and enable metrics analytics for incident investigation. Further migration work remains in progress.
